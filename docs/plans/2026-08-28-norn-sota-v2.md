## 2. Veille harness (juin → août 2026) — ce qu'on retient

**DeepSeek Harness (dsh)** — micro-kernel « everything is a plugin » (Cordis), 453K lignes TS. Trois mécanismes retenus pour Norn:
1. *Log append-only = artefact authoritative*: chaque appel LLM valide que les messages sortants sont dérivables du log de session (invariant byte-pour-byte). → Vague 1-A (version proportionnée: hash chain, strict en CI).
2. *Tests par replay*: les logs de session sont les fixtures; un provider mock déterministe rejoue; le fichier sert d'entrée ET d'oracle; zéro clé API en CI, drift = diff. → Vague 1-A.
3. *Sandbox fail-closed*: confinement argv-wrapping (seatbelt/Landlock/bubblewrap), si confinement demandé mais indisponible → exception, jamais d'exécution nue; escalade modélisée comme interaction utilisateur. → Vague 1-C.

Non retenu: la plugin-isation intégrale (micro-kernel). Contraire au pari Norn « contrôle architectural total + modifications additives ». Réévaluer si le codebase dépasse la tractabilité mono-équipe.

**pi (Zechner/Ronacher)** — minimalisme radical (4 tools), contrôle total du contexte, extensions self-modifiantes, anti-MCP (SDKs générés). Recoupe Viktor Idée B (Phase 5, différée). Leçon actionnable immédiate: garder la surface d'outils petite et le system prompt court — déjà l'esprit de `minify_tool_schemas` et `dynamic_tools`.

**AXI** (axi.md, kunchenguid/axi) — 10 principes d'ergonomie tool-output: sorties token-efficient, schémas minimaux (3-4 champs + opt-in `--fields`), troncature avec indices de taille + `--full`, agrégats pré-calculés, états vides explicites, erreurs structurées, suggestions next-step. Benchmark: 100% succès/$0.074 vs MCP 99%/$0.100. → Vague 2 (passe AXI sur les ToolResult Norn).

**HarnessAudit** (arXiv:2605.14271) — l'audit doit porter sur la trajectoire complète, pas l'output final; les violations s'accumulent avec la longueur de trajectoire. Conforte: JSONL first-class + replay + event `sandbox.decision`.

**Herdr** — multiplexer d'agents (tmux-like). Orthogonal: Norn serait un agent hébergé. Rien à intégrer.

## 3. Vague 1 (cette itération) — 4 workstreams, additifs

### A — Fiabilité/Audit
- **A1 ThreadLedger** (`src/norn/core/thread_ledger.py`): hash chain sha256 à l'append; vérif fast-path par identité en prod (fail-open, event `invariant.violation`), re-hash complet sous `NORN_STRICT_INVARIANTS=1` (fail-hard, activé en autouse dans les tests → toute la suite devient harnais anti-mutation). `verify_derivation`: tout message sortant non-SYSTEM doit être membre du history (le résumé SYSTEM = seule injection autorisée).
- **A2 Record/Replay** (`src/norn/core/replay.py`): `RecordingProvider` (wrapper LLMProvider, JSONL par session: meta + exchanges avec `request_hash` canonique) + `ReplayProvider` (curseur séquentiel, mismatch → `ReplayDriftError` avec diff, `assert_exhausted()`). CLI `--record`, config `recording:`, fixtures `tests/fixtures/replay/`.

### B — Perf: brancher l'existant
- **B1** flag `coderag` (off) + enregistrement des 3 tools au registry.
- **B2** `--judge` sur `bench run` (LLM-as-judge, `judge_task` existant) + metrics par tâche (`tool_counts`, `llm_calls` depuis les JSONL de session, best-effort).
- **B3** dé-hardcode `cli/bench.py`: tiers depuis `BenchConfig`, `--model provider/model` honoré, `--n-runs`; `parallel_tasks` différé (racé avec last_session).
- **B4** `norn bench guard` (W3.3): mini-bench easy tasks vs baseline `results/guard/`, `detect_regressions`, exit 1 si régression, `--revert-lessons` (backup `lessons.md.bak` pris par `/reflect`).
- **B5** suppression flag `bench` mort.

### C — Sécurité: sandbox fail-closed (seatbelt)
- Module `src/norn/sandbox/` (models + seatbelt): politiques `read-only` / `workspace-write` / `danger-full-access`, profil seatbelt deny-default inline (`-p` + `-D` params, realpath systématique), `(allow network*)` opt-in.
- `BashTool`: flag `sandbox` (off); indisponible → `ToolResult(SandboxUnavailable)`, **jamais d'exécution non confinée**; `danger-full-access` → escalade via prompt utilisateur (PromptFn existant). Event `sandbox.decision`.
- Orthogonal aux permissions (permission = droit de partir; sandbox = confinement pendant l'exécution). `yolo + sandbox=on` = autonomie confinée.
- Linux (bubblewrap/Landlock): extension future documentée, non implémentée.

### D — Coût: byte-stable prompt + métriques cache
- **D1/D2** flag `stable_prompt` (off): préfixe statique-session (instructions + env + repo map) séparé du suffixe volatil (mémoire/leçons) par `CACHE_BREAK`; split en 2 blocs `cache_control` côté `llm.py` (marqueur strippé si caching off). Warning si `dynamic_tools` + cache (antagonistes).
- **D3** `TokenUsage.cache_read_tokens`/`cache_creation_tokens`; `stream()` émet enfin `llm.complete` (measure_and_log) → métriques cache en session interactive.
